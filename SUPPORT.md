# 🆘 Support

This document outlines how to get help with the NetApp open source solutions.

## 📋 Supported Versions

The Neo UI framework supports the Neo backend API versions:

| Version | Supported          |
| ------- | ------------------ |
| 4.x.x   | ✅ Yes             |
| 3.x.x   | ✅ Yes             |
| 2.x.x   | ❌ No              |
| < 2.0   | ❌ No              |

## Reporting Bugs

For reporting bugs, please use the GitHub Issues tracker: [link to issues page](https://github.com/NetApp/neo-ui-framework/issues)

When reporting a bug, please include:
* Use the provided template
* A clear description of the issue.
* Steps to reproduce the bug.
* A description of your environments.
* Any relevant error messages.

## Asking Questions

If you have questions about using the project, please:
* Check the documentation provided with each projects.
* Reach out to your EAP contact person 
* For any feature request, please use the GitHub Issues tracker: [link to issues page](https://github.com/NetApp/neo-ui-framework/issues)
